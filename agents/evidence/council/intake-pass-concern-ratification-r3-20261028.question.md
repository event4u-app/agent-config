## Background

The repository owner answered open question OQ-25 on 2026-10-28: the reminder to check a task prompt for gaps only the owner can close should be shipped in the package's own hooks, on by default, with no new settings key, firing only on task prompts, and the agent — not the hook — decides whether a gap is owner-owned.

## Round 2 and what changed since

Round 2: both seats found no code defect and refused only on the record — the manifest's COST comment named the per-task-prompt context but not that the lazy chunk loads and the classifier runs on EVERY prompt of every bound host. Commit `36bd8fb5bd` changes that comment only (and the compiled manifest that carries it); no code changed. The comment now reads, verbatim:

```
# COST, named: on EVERY prompt the dispatcher loads the ~10 KB lazy chunk
# (one `require`, cached for the rest of that dispatch) and runs the
# classifier, emitted or not. On a task prompt it adds about 470 B of context,
# every host binding the slot, repeated per task prompt; a false positive adds
# that line and may prompt one owner question the task did not need.
```

## Round 1 and what changed after it

Round 1 (both seats) refused on two grounds, plus smaller findings. Each is addressed in commit `34613b01b5`:

- **The compiled manifest was missing from the diff.** It is a one-line minified JSON regenerated by `compile_hook_manifest`; its change is shown below as a key-sorted `jq -S` diff of base against head, and `check_generator_sync` plus `tests/hooks/hook_manifest_compiled.test.ts` confirm the committed file equals a fresh compile.
- **The question predicate.** A prompt is now a question when its LAST SENTENCE ends in `?` or its FIRST WORD is interrogative (EN/DE list). Scope decision, stated in the code and pinned by tests: a polite request phrased as a question ("Could you add retries…?") is deliberately silent, because the repository's rule `question-not-instruction` says a question is answered or clarified, never worked on — the pass only runs before work. An embedded question followed by an instruction ("The export is slow? Add an index…") fires.
- **"go ahead" / "ok" silenced tasks.** Only resume orders (`mach weiter`, `weiter`, `continue`, `go on`) are continuations at any length; a short acknowledgement falls under the six-word floor and a longer one is treated as a task.
- **Narrow release vocabulary.** Added `don't ask`, `do not ask`, `without asking`, `proceed autonomously`, `ohne (Rück)fragen`, `frag nicht`.
- **The injected line referenced a file path.** Removed; the line is self-contained.
- **Unnamed costs.** The manifest entry now names them: about 470 B of context per task prompt on every host binding the slot, repeated per task prompt, and the chance of one unneeded owner question on a false positive.
- Tests: 24 cases now (question-form request, trailing-qualifier question, punctuation-free German question, long resume order, two release phrasings, go-ahead task, ok-task, embedded-question task, multiline task). The chunk grew to 9,807 B; its ceiling is 10,800 B.

Not addressed, with reason: a per-project setting for the concern — the owner ruled out a new settings key for this (OQ-25, and the 2026-10-12 line ADR-293); the env kill switch stays the only off switch. Chunk-load failure is covered by the existing generic `tests/hooks/lazy_concern_fallback.test.ts`, not by a concern-specific test.

## What the change does

1. A new concern `intake-pass` (`src/scripts/hooks/intake_pass_hook.ts`), `severity: advisory`, `effect: context`, `fail_closed: false`, bound to `user_prompt_submit` on every platform that binds that slot. On a prompt it classifies as a task (not a question, not a continuation, not a slash command, not a harness turn, at least six words, no explicit interview or "just do it" phrase) it emits one `additional_context` line of about 400 bytes naming the intake pass. Otherwise it emits nothing. Kill switch: `AGENT_CONFIG_NO_INTAKE_PASS=1`. It never rewrites the prompt and never blocks.
2. Workers drop it (role axis `worker.drop`), the same reason `delegation-nudge` is dropped there.
3. Its body ships as a lazy chunk (`hook_chunks.mjs`, `LAZY_CONCERNS`), not in the dispatch bundle. 4. Tests: `tests/hooks/intake_pass_hook.test.ts` (24 cases; the question filter was neutralised once and the suite went red, then restored), two existing tests updated for the new concern count and the worker drop list.

Verified locally: the hook-bundle composition gate is green at the new ceiling, `lint_hook_manifest` exit 0, `bench_hook_injection` exit 0, the affected hook and discovery suites pass, `tsc --noEmit` and eslint clean on the touched files.

Not in the diff below: `dist/` projections, the owner-questions and roadmap bookkeeping, the five `workspaces:` frontmatter edits on the interview commands, and the removal of the prompt optimizer's persona — none of them touches a gated file.

```diff
+const RELEASE = /\b(?:just\s+do\s+it|mach\s+einfach|einfach\s+machen|no\s+questions|don'?t\s+ask|do\s+not\s+ask|without\s+asking|proceed\s+autonomously|keine\s+(?:r[üu]ck)?fragen|ohne\s+(?:r[üu]ck)?(?:fragen|nachfragen)|frag\s+nicht)\b/i;

+export const INTAKE_LINE =
+  "<intake-pass>Before the first write, sort this prompt's gaps: a fact → look it up; " +
+  "a technical choice → decide it and name it as your call in the hand-back; " +
+  "an owner-owned gap (product meaning, a business constraint, taste) → ask ONE question first, " +

+function lastSentence(text: string): string {
+  const parts = text.split(/(?<=[.!?])\s+/).filter((s) => s.trim() !== "");
+  return (parts[parts.length - 1] ?? text).trim();
+}
+
+/**
+ * A question is answered, never worked on (rule `question-not-instruction`), so
+ * the pass stays silent on one — including a polite request phrased as a
+ * question, which the agent answers or clarifies first. A prompt counts as a
+ * question when its last sentence ends in `?` or its first word is interrogative.
+ */
+export function isQuestion(text: string): boolean {
+  return /\?\s*$/.test(lastSentence(text)) || INTERROGATIVE.test(text);
+}
+
+export function isTaskPrompt(prompt: string): boolean {
+  const text = prompt.trim();
+  if (!text || text.startsWith("/")) return false;
+  if (isSyntheticPrompt(text)) return false;
+  const words = text.split(/\s+/).length;
+  if (RESUME.test(text)) return false;
+  if (words < MIN_TASK_WORDS) return false;
+  if (isQuestion(text)) return false;
+  if (INTERVIEW.test(text) || RELEASE.test(text)) return false;
+  return true;
+}
+
+function _isObject(v: JsonValue | undefined): v is JsonObject {
+  return typeof v === "object" && v !== null && !Array.isArray(v);
+}
+
+function _extractPrompt(payload: JsonObject): string {
+  for (const key of ["prompt", "userPrompt", "user_prompt", "message", "text"]) {
+    const v = payload[key];
+    if (typeof v === "string" && v.trim()) return v;
+  }
+  return "";
+}
+
+export function main(): number {
+  if (process.env["AGENT_CONFIG_NO_INTAKE_PASS"] === "1") return EXIT_ALLOW;
+  let envelope: JsonValue = {};
+  try {
+    const raw = readHookStdin();
+    envelope = raw.trim() ? (JSON.parse(raw) as JsonValue) : {};
+  } catch {
+    return EXIT_ALLOW;
+  }
+  const env: JsonObject = _isObject(envelope) ? envelope : {};
+  const event = env["event"];
+  if (typeof event === "string" && event !== "" && event !== "user_prompt_submit") return EXIT_ALLOW;
+  const payload = _isObject(env["payload"]) ? (env["payload"] as JsonObject) : env;
+  if (!isTaskPrompt(_extractPrompt(payload))) return EXIT_ALLOW;
+  process.stdout.write(
+    `${JSON.stringify({ decision: "warn", reason: "intake-pass: task prompt", additional_context: INTAKE_LINE })}\n`,
+  );
+  return EXIT_WARN;
+}
+
+// Bundle-safety: never auto-run when inlined into an esbuild bundle.
+declare const __AGENT_CONFIG_BUNDLE__: boolean | undefined;
+function _isCliEntry(): boolean {
+  if (typeof __AGENT_CONFIG_BUNDLE__ !== "undefined" && __AGENT_CONFIG_BUNDLE__) return false;
+  if (process.argv[1] === undefined) return false;
+  if (import.meta.url === pathToFileURL(path.resolve(process.argv[1])).href) return true;
+  try {
+    return fs.realpathSync(fileURLToPath(import.meta.url)) === fs.realpathSync(path.resolve(process.argv[1]));
+  } catch {
+    return false;
+  }
+}
+
+if (_isCliEntry()) {
+  process.exit(main());
+}
```
