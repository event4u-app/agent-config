## Pair 1 — `road-to-an-installed-layer-that-is-thinned` → `road-to-a-setup-that-decides-itself`

**Verdict: keep apart, 2/2.**

- **anthropic:** the fold is *"architecturally premature until the
  rollback-vs-no-rollback policy fork is explicitly resolved; the work
  dependency is real but insufficient to close the design question."* Folding
  would record the winning policy *"as a side effect of file organization"*.
- **openai:** *"Keep apart for now. The roadmaps contain an unresolved policy
  conflict, not merely overlapping execution."* A dependency from source 3.5 to
  target 5.3 *"proves sequencing, not common accountability"*, and absorbing
  work into the target *"is not an owner decision to eliminate an operational
  escape hatch"*.

Both seats also named the concurrent-execution hazard: the target is being
executed by another session today, so moving steps into it would change the
identifiers that session is working against.

**Dissent:** none on the verdict. Where the seats differed: anthropic read the
evidence as leaning toward the target's form winning; openai pushed back
hardest on the target removing the rollback setting at all, because the
selector would then control both normal operation and the way to escape its
own output. Neither question is decided here.

**What would reopen it (both seats):** a recorded decision that the source's
rollback contract is superseded, and a step-by-step mapping showing the source
has no rollout or recovery work of its own left.

## Pair 2 — `road-to-svg-witness-provenance` → `road-to-type-with-a-witness`

**Verdict: keep apart, 2/2.**

- **anthropic:** the source hardens the consumption rules for a security
  discharge, the target consumes the same witness for typography fidelity, so
  `disjoint` holds.
- **openai:** shared use of `ui:render --profile asset` *"does not establish
  roadmap-level cohesion"*; the case for folding would need both files to
  change the same witness schema, deploy atomically and share acceptance
  criteria, and *"the current artefact establishes only command reuse"*.

**Dissent:** none. openai added that the shared renderer deserves an explicit,
versioned contract so that two roadmaps do not hide coupling; recorded, not
scheduled here.
