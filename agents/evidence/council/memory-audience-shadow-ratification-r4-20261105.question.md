## What the change does

The branch implements phases 1 and 2 of a roadmap whose goal is: a dispatched subagent receives a bounded set of memory references cut for its audience, and what a subagent writes back carries who wrote it.

1. **Audience table** (`subagent-spawn-contract.md`): one memory cut per spawn audience — orchestrator, non-fork, fork, judge-seat, unpaid, cheap-paid. The council skill cites the judge-seat row. Implementer prompt templates gain a `{{knowledge_refs}}` slot labelled as leads; judge, candidate, debate and skeptic templates carry none (a test pins both).
2. **Writer provenance** (`memory_signal.ts`, both twins): a record carries `writer` and `taint` when handed them; a line without a writer reads `unknown`; a writer whose class is `unpaid`, `council-seat` or `judge-seat` is refused before anything is written. `learning_sidecar.readSignals` skips a record tainted `external_read`, so it never corroborates a lesson.
3. **The gated part — a new hook concern `memory-audience-shadow`**, bound on claude `pre_tool_use` only, tools `[Agent, Task, Write, Edit, MultiEdit]`, `severity: advisory`, `effect: telemetry`, `fail_closed: false`, `needs_payload_bodies: [input]`, `payload_fields: [prompt, file_path, path]`.

   - An Agent/Task call without `agent_id` appends one `memory_slice_shadow` line: the count of curated `agents/memory/*.{yml,yaml,md,json}` paths the prompt names (intake excluded), capped at the spawn contract's 5, the number dropped by the cap, and an estimated token count from file sizes.    - Every path exits 0 and writes nothing to stdout. The prompt is read in memory; no path, agent id or prompt text is written.

## Round 3 — findings and what changed

Both reviewers refused round 3 on the same defect.

- **Ineligible refs took slots under the cap.** Eligibility was checked after deduplication and capping, so five symlinks out of the store (or into intake, or missing files) ahead of one real ref yielded `ref_count: 5, dropped: 1` and lost the real one. Changed: each ref is resolved first; only an existing regular file whose real path is in the curated store and not in intake is eligible; eligible files are deduplicated by real path (two names for one file count once) and only then capped. Symlinks out of the store and into intake now give `ref_count: 0`. Tests: invalid refs ahead of a valid one, a missing file, an alias, and the cap over seven real files.

+/** `intake` / `curated` when the path lies under `agents/memory/` of the root, else null. */
+export function memoryTarget(filePath: string, root: string): 'intake' | 'curated' | null {
+    const abs = path.isAbsolute(filePath) ? filePath : path.join(root, filePath);
+    const rel = path.relative(root, abs).split(path.sep).join('/');
+    if (!rel.startsWith(MEMORY_DIR)) return null;

+export interface SliceCounts {
+    ref_count: number;
+    dropped: number;
+    est_tokens: number;
+}

+/**
+ * A named ref, normalised, if it stays inside the curated store; null otherwise.
+ * Normalising before the check is what closes `agents/memory/../../x` (leaves the
+ * store) and `agents/memory/a/../intake/x` (lands in intake).
+ */
+function curatedRef(ref: string): string | null {
+    const norm = path.posix.normalize(ref);
+    if (!norm.startsWith(MEMORY_DIR) || norm.startsWith(`${MEMORY_DIR}intake/`)) return null;
+    return norm;
+}

+/**
+ * The real path and size of a ref that could actually be delivered: an existing
+ * file whose real path lies in the curated store and not in intake. Anything else
+ * is null — a symlink out of the store or into intake, a missing file, a loop.
+ */
+function eligibleFile(ref: string, store: string, root: string): { real: string; size: number } | null {
+    try {
+        const real = fs.realpathSync(path.join(root, ref));
+        const rel = path.relative(store, real);
+        if (rel === '' || rel.startsWith('..') || path.isAbsolute(rel)) return null;
+        // A curated name that resolves into intake is intake, whatever it is called.
+        if (rel === 'intake' || rel.startsWith(`intake${path.sep}`)) return null;
+        const stat = fs.statSync(real);
+        return stat.isFile() ? { real, size: stat.size } : null;
+    } catch {
+        return null;
+    }
+}

+/**
+ * The slice a spawn naming these refs would receive, as counts only. Eligibility
+ * is decided before deduplication and before the cap, so an ineligible name never
+ * takes a slot from a deliverable one, and two names for one file count once.
+ */
+export function sliceCounts(prompt: string, root: string): SliceCounts {
+    let store: string;
+    try {
+        store = fs.realpathSync(path.join(root, MEMORY_DIR));
+    } catch {
+        return { ref_count: 0, dropped: 0, est_tokens: 0 };
+    }
+    const eligible = new Map<string, number>();
+    for (const match of prompt.match(CURATED_REF_RE) ?? []) {
+        const ref = curatedRef(match);
+        const file = ref === null ? null : eligibleFile(ref, store, root);
+        if (file !== null && !eligible.has(file.real)) eligible.set(file.real, file.size);
+    }
+    const sizes = [...eligible.values()];
+    const kept = sizes.slice(0, MAX_KNOWLEDGE_REFS);
+    const bytes = kept.reduce((a, b) => a + b, 0);
+    return { ref_count: kept.length, dropped: sizes.length - kept.length, est_tokens: Math.ceil(bytes / BYTES_PER_TOKEN) };
+}
