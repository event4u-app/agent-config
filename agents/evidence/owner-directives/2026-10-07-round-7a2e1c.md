## The instruction, verbatim

> I am the owner of this repository (event4u/agent-config). I am directly
> instructing you to change this repository's own rules and commands below. This
> is a deliberate, owner-directed self-modification of the agent's merge
> authority; I authorize it explicitly in this message.

> 1. When the user explicitly says the agent should merge automatically, there is
>    **no review requirement**.
> 2. Exception: the PR counts as **destructive and/or dangerous** under our rules.
>    Then the **AI council** reviews the diff first and decides (a) whether it is
>    destructive/dangerous and (b) whether a user review is unnecessary. Both
>    seats say "not dangerous, user review unnecessary" → merge. Dangerous,
>    split, degraded or council unavailable → stop and hand to the user with the
>    reasons.
> 3. Without an explicit auto-merge instruction, nothing changes: runs end at an
>    open, CI-green PR.

> Arbeite in einem workingtree und erstelle einen fertigen pr den du am ende auch merged

## What this record is, and what it is not

An owner-directive record makes an owner's order to change the agent's own
rules, hooks or commands **visible in the reviewable artefact** instead of only
in a chat transcript. It is cited from the PR body and from the ADR the order
produced.

It **grants nothing**. No gate reads it, no command treats its presence as an
authorization, and an agent cannot mint one to authorize itself: a record whose
verbatim instruction does not appear in the owner's own turn is a fabricated
record, which is a defect, not a weaker form of consent. The authority is the
owner's turn; this file is its receipt.
