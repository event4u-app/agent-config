## What was ratified

- **One authority expansion, classified as such by both seats.** A
  `session_start` concern that asks the user for a GitHub star, which ADR-286
  § D2 had refused and the owner reopened in ADR-301. It is bound on `claude`
  only and speaks through the existing user channel (`systemMessage`), never
  into model context.
- **Its bounds.** First ask 7 days after the concern first runs, then at most
  once per 30 days; the ask counts on emission, its state is written first, and
  a failed write means no ask. Each ask is claimed for the exact state it
  follows by a never-expiring `wx` file, so concurrent sessions cannot both ask.
  An unreadable user-global settings layer suppresses it. Settings are read from
  user-global layers only; a test pins that a project-level block is never read.
  No network, no identity read. Both stop commands are printed in full.
- **The limit for anything later** (ADR-301 § D4): no further ask without its
  own owner ruling and record, keeping every property above.

## How it got there

Six rounds, all 2/2 present. Round 1 refused 2/2 (interval gated on the
delivery receipt, so a lost receipt asked every session). Round 2 split
(unreadable settings read as "no opt-out"). Round 3 split (atomic replacement is
not mutual exclusion). Round 4 refused 2/2 (the 60 s expiring lock was an ABA
race). Round 5 split (the printed opt-out was not a command). Round 6 ratified
2/2. Each refusal named a real defect, each was fixed with a test seen red
first, and the lock and claim fixes were sabotage-checked (neutralised →
red → restored → green).

## Non-blocking points carried, not fixed here

- Aggregate notification pressure on `session_start` is limited by ADR-301 § D4
  as governance text only; an enforceable budget across notice concerns does
  not exist. Raised by the openai seat in round 6 as a governance question, not
  a defect of this concern.
- A test for `notice.write()` throwing after the state is written is absent;
  the behaviour is fail-closed (the interval is consumed, nothing repeats).
