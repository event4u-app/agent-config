## The unit, and why it is not this disk

The census is taken over the **projection source** `dist/agent-src/rules`, minus the
ADR-004 `type: manual` rules no per-tool tree ever receives. That is the UPPER BOUND a
host loads: an unscoped, un-deduplicated consumer install.

Reading it off the local trees instead would measure this machine. Two install-local
filters shrink a maintainer checkout below what a consumer receives — user-scope dedup
(a rule byte-identical to a user-scope twin is skipped) and workspace/pack scope. Both
are real, both differ per install, and step 0.1 requires a re-run at the same pin to be
byte-identical. Every scope narrowing moves a host DOWN from the figure below, never up.

**This measures delivery, not consumption.** Whether a host READS what it is handed is
the axis `docs/enforcement-by-host.md:18-28` owns; a host with a tree it never loads
would look identical here.
