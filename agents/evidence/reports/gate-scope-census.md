## Why

ADR-051 moved the source container. Gates carrying a hardcoded literal root
kept exiting 0 while scanning zero files, for weeks, because nothing recorded
what each gate was supposed to be reading. This census is that record: every
gate, every root it reads, and how much is under that root **today**. The next
container move shows up here as a count dropping to zero in a diff, instead of
as a green checkmark over an empty directory.

## Scope — what this census does NOT cover

- **The unit count is files under the root, not the gate's own unit.** A gate
  filtering to `*.md` reports fewer units than the row shows. The number is a
  movement detector, not a gate-internal assertion — reimplementing 200 filters
  here would rot on the first filter change.
- **Roots the static extractor cannot see** are listed as
  `(no literal root extracted)`, not omitted. Known blind spots: roots read from
  a config file, bases outside the accepted repo-root identifier set, glob-library
  walks, and template-literal paths. Those gates are uncovered, and the row says so.
- **Nested helper directories** under `src/scripts/` are outside the population —
  the sweep reads the top level only.
- A dead root here is a *finding*, not a repair. Repairs are the roadmap's job;
  this file only makes them visible.
