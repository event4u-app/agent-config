# Architectural Review

## 1. Boundaries

**Module boundaries:**

- **Package core** (`.agent-src.uncompressed/`) — source of truth; edited by maintainers; single write zone.
- **Generated artifacts** (`.agent-src/`, `.augment/`, `.claude/`, `.cursor/`, `.clinerules/`, `.windsurfrules`) — read-only; regenerated by tooling; multiple read zones per tool surface.
- **Consumer project space** (`agents/`, `.agent-settings.yml`, project source) — editable by consumers; overrides and project-specific docs.
- **Contracts / docs** (`docs/contracts/`, `docs/architecture.md`, `README.md`) — governance layer; defines Iron Laws, routing, and portability.

**Layer boundaries:**

- **Kernel layer** — 9 Iron-Law rules always loaded (`.agent-src/rules/`).
- **Router layer** — tier-1 / tier-2 routing logic (`.agent-src/router.json`).
- **Projection layer** — tool-specific bundles (Augment, Claude Code, Cursor, Cline, Windsurf, Gemini CLI, Claude.ai).
- **Consumer layer** — installed artifacts + project overrides.

**Trust zones:**

- **Trusted write zone** — `.agent-src.uncompressed/` (maintainers only).
- **Untrusted write zone** — `agents/`, `.agent-settings.yml` (consumers can override).
- **No-write zones** — all generated artifacts (`.agent-src/`, `.augment/`, etc.).

The boundary enforcement is explicit: "Generated trees ... **must never be hand-edited**" (Artefact A, line 7) and "Do not edit `.augment/` or `.agent-src/` here" (Artefact B, line 43). The package-root AGENTS.md states edit location three times (lines 7, 20, emergency-triage #3), signaling strong boundary discipline.

## 2. Strongest Design Decision

**Single source of truth with multi-tool projection.**

The design forces all edits into `.agent-src.uncompressed/` and regenerates tool-specific surfaces via `task sync` + `task generate-tools`. This creates:

- **Zero drift** — no possibility of `.augment/rules/foo.md` diverging from `.claude/rules/foo.md`.
- **Tool parity** — Augment, Claude Code, Cursor, Cline, Windsurf, Gemini CLI all see identical content.
- **Change atomicity** — one edit in `.agent-src.uncompressed/` propagates everywhere.

Cited in Artefact A, lines 5–7: "Edit `.agent-src.uncompressed/` only. Generated trees ... regenerate from `task sync` + `task generate-tools` and **must never be hand-edited**." The Iron-Law rule `augment-source-of-truth` (line 17) further governs this. The consumer template reinforces it (Artefact B, lines 43–44).

This decision prevents the common anti-pattern of tool-specific forks and manual sync hell. It is the architectural keystone.
