## Follow-up work — out of scope for this roadmap

Surfaced by the council but not actioned here. Each would need its own
roadmap with a frontmatter-migration plan and projection-fidelity test.

1. **Top-level sprawl — 52 commands at directory `.`** Cluster proposals from the council:
   - `delivery:` cluster — absorb `bug-fix`, `bug-investigate`, `estimate-ticket`, `refine-ticket`, `quality-fix`, `prepare-for-review`, `review-changes`, `upstream-contribute`, `jira-ticket` (9 commands).
   - `project:` cluster — absorb `project-analyze`, `project-health`, `rule-compliance-audit`, `threat-model`, `package-reset`, `package-test`, `cost-report` (7 commands).
   - `e2e:` cluster — absorb `e2e-heal`, `e2e-plan` (2 commands, fixes orphan status).
   - Expected reduction: 52 top-level → ~34 top-level. Needs its own roadmap because every move requires updating frontmatter `cluster:`, regenerating the router, and updating every cross-reference in the docs and rules.

2. **Tier enforcement audit** — 76 of 109 commands (70%) are tier-2. The council asked whether host agents actually honour the tier-0 / 1 / 2 gating contract or load the full surface regardless. If runtime ignores tiers, the cognitive-load problem is structural and the cluster work above is necessary but insufficient.

3. **Hidden overlap in `council:` cluster** — pairwise cosine missed potential `council:default` vs cluster-entry-point (`council`) overlap. `council:default` at 284 lines vs `council` at 102 lines suggests `council:default` might be a superset / fallback. Needs description-level read, not cosine.

## Phase 2 implications

With 0 merges and 0 retires, **Phase 2 is a documented no-op**: the four
overlap pairs and the four retire candidates the council surfaced all
turned out to be intentional structural patterns (scope ladders, union
dispatchers, thin aliases, tier-gated specialists), not redundancy. The
cognitive-load problem is real but lives in the top-level sprawl, not in
the overlap pairs — and addressing it requires the follow-up roadmaps
above, not the consolidation pattern this roadmap framed.
