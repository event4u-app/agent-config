# Road to retire stale authoring-source pointers (`.agent-src.uncondensed/` → `src/`)

> **Council decision** (claude-sonnet-4-5 + gpt-4o, 2026-07-28, 3-round debate).
> The question: given no active roadmap is autonomously completable, is the
> deferred #989 `.agent-src.uncondensed/` cleanup the right fully-autonomous
> roadmap, and how is it scoped? Converged: **yes, do it autonomously** —
> deterministic per-reference classification, **conservative KEEP on any
> ambiguity**, **no "needs-audit" markers** (a disguised human gate), **one PR**,
> CI/tests as the safety net; false-positive prose edits are cheap and caught in
> review, silent stale pointers perpetuate the debt.
>
> **Host scope override (grounded in a source check the council did not have):**
> `.agent-src.uncondensed/` is NOT dead debt — it is a **live generated
> intermediate**. `task sync` regenerates it from `src/`, and the
> condensation / router / runtime-registry scripts read it as a real path root
> (`check_condensation.ts SOURCE_DIR`, `compile_router.ts RULES_DIR`,
> `runtime_registry.ts`, `lint_role_experiences.ts`, …). Migrating those code
> constants would BREAK the build. So the council's "migrate operational `.ts`
> literals" branch is rejected. **Scope is prose-only:** the stale
> *authoring-source* pointers that tell a reader/agent to EDIT
> `.agent-src.uncondensed/` as the source of truth — which is wrong per ADR-051
> (you edit `src/`; `.agent-src.uncondensed/` is a generated intermediate you
> never hand-edit). This continues exactly the #989 fixes (README, thin-root).

## Goal

Retire the misleading *authoring-source* pointers that direct editing to the
generated `.agent-src.uncondensed/` intermediate, repointing them at `src/`,
and broaden the #989 `check_source_pointer_freshness` gate to lock the cleaned
authoring files against regression. **Zero code / path-constant changes** — the
build pipeline's live references to `.agent-src.uncondensed/` stay untouched.

## Context (measured 2026-07-28 — do not relitigate)

- 185 files under `src/` reference `.agent-src.uncondensed/`. Breakdown:
  - **99 `.ts` (+ 7 `.sh`, 5 `.json`, hooks)** — live code constants / real
    path roots (condense, router, registry, guards, detectors). **KEEP ALL.**
  - **69 `.md`** — 169 token lines; classified **MIGRATE=43 / KEEP=126** by 3
    parallel subagents. MIGRATE = *edit-here / source-of-truth* authoring
    claims; KEEP = generated-intermediate / pipeline descriptions, catalog-asset
    paths, `validator_ignore` config, `path_prefix` triggers, fenced code,
    historical / ADR mentions.
- `.agent-src.uncondensed/` EXISTS in a synced tree (generated by `task sync`);
  a live intermediate, not a dead directory.
- #989 shipped `check_source_pointer_freshness` (fails when an authoring
  allowlist file names the retired tree as current source) + the audited
  `<!-- pointer-freshness: historical -->` exemption marker. This roadmap
  extends that allowlist.
- Settings: template defaults; `quality.local_auto_run: false` → NO
  full-pipeline CI steps in this roadmap; only targeted verification of the
  broadened gate + its test (new-gate carve-out) runs locally.

## Explicitly NOT in this roadmap (council do-not-build + host override)

- **No `.ts` / code / path-constant edits** — the pipeline's
  `.agent-src.uncondensed/` references are live; touching them risks the build.
- No `needs-audit` markers (disguised human gate — council-rejected).
- No blind find-replace across all 185 files.
- No full ADR-051 code-level retirement of the intermediate (that is a
  separate structural refactor needing maintainer direction + CI proof).
