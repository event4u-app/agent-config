# Roadmap: step-16 — telegraph substance (security gate, bench corpus, input condensation, telemetry, validator)

> Convert the telegraph-speak dialect from a documented algorithm into a measured, observable, enforced condensation surface. Closes the four substantive gaps the AI Council surfaced on 2026-05-16 against the sunset `step-10-telegraph-parity` parity-chase (no telegraph-specific benchmark corpus, no input-side memory condensation, no telemetry, no mechanical carve-out validator) and the four high-leverage gaps the upstream-deepscan amendment surfaced the same day (no sensitive-path denylist, no terse-control-arm methodology, no published bench runs, no per-conversation cost lens / summary JSON contract).

**Measured-vs-claimed disclaimer:** All public telegraph savings numbers (~65–75 % output, ~46 % input) are upstream claims and have not been measured against this repo's seven byte-exact carve-outs. Anthropic's Round-2 refinement estimates the realised output savings at **40–50 %** once the carve-out tax is paid; that estimate is itself unmeasured. Treat every percentage in this roadmap as `[!]` until Phase 1 produces a fresh `bench/reports/telegraph-vXY.{json,md}`.

## Context

step-10 was sunset because it chased marketing surface (intensity tiers, lifetime counter, statusline) without measurement. The Council audit confirmed three real gaps and one half-gap, and falsified two other findings (the "no benchmark pipeline" and "`speak_scope` underspecified" claims) against the codebase. The upstream-deepscan amendment (2026-05-16) then surfaced four high-leverage gaps the parity-chase missed: a sensitive-path denylist that Telegraph ships and we don't (P0 security blocker against the upcoming input-side condensation in Phase 2), a terse-control-arm benchmark methodology that quantifies savings against an `Answer concisely.` baseline rather than raw output, an empty `bench/reports/` directory while Ruflo commits 8 historical runs, and per-conversation / summary-JSON telemetry primitives that close the remaining `–` rows on the parity scorecard. This roadmap addresses only the validated gaps, in dependency order: security first (so condensation can never leak a `.env`), measurement second (so telemetry has a calibrated multiplier), enforcement before default-ON (so the Iron-Law carve-outs are mechanically guarded, not honour-system), and input-side condensation as a bounded extension (consumer-facing skill, not a rewrite of the source-of-truth `condense.py`).

## Notes

- **Order matters.** Phase 0 gates Phase 2 (security floor). Phase 3 needs Phase 1's multiplier (the `vs_terse` arm, not `vs_raw`); Phase 4 needs Phase 1's corpus to prove the validator catches real regressions. Phase 0 + Phase 1 are independent and can ship in parallel.
- **No default-ON flip in this roadmap.** Flipping `speak_scope` default to `prose_only` (or `aggressive`) is a separate decision that lands once the kill-criterion is met. This roadmap produces the evidence; a follow-up roadmap (or maintainer call) makes the flip.
- **No intensity-tier expansion.** The Council's "missing tiers" finding was half-validated; the existing `off` / `prose_only` / `aggressive` tiers stay until bench data proves a third tier is needed. Out of scope here.
- **No subagent / MCP-tool-description condensation.** Confirmed out of scope (Node/npm dependency, orthogonal to dialect).
- **No LLM-driven condensation in Phase 2.** Telegraph's upstream `condense.py` calls Anthropic API; our Phase 2 stays offline / heuristic. The upstream-deepscan finding was scored SPECULATIVE (no demand signal) — defer with trigger: ≥ 2 consumers request smarter condensation OR a quality complaint against the heuristic path. Documented here so the deferral is auditable.
- **No router-outcome-feedback loop.** Ruflo's `outcome.mjs` was scored INFERRED (router-learning requirement unvalidated against our static-router design). Defer with trigger: explicit decision on `router v2 with learning`.
- **No Prometheus / webhook export.** Ruflo's `export.mjs` was scored INFERRED (no consumer demand for external observability). Defer with trigger: user requests "export to monitoring system X". The Phase-3 `cost-summary-schema.md` is the upstream-stable surface a future export script would wrap.
- **No multi-tool projection to Junie / Kiro / Roo / Codex.** Telegraph covers those, we cover Augment / Claude / Cursor / Cline / Windsurf. Different surface, neither superset. Defer with trigger: ≥ 3 consumers request OR competitor adopts our positioning on those surfaces.
- **No per-plugin smoke granularity.** Ruflo ships `smoke.sh` per plugin (~20K each); we ship per-tier smoke. Score INFERRED (failure mode unproven against our tier architecture). Defer with trigger: per-tier smoke misses a regression a per-plugin smoke would catch.
