# DESIGN.md — agent-config settings UI

The browser wizard and settings screens. Product register: one reliable family,
contrast from weight and scale, design serves the task.

## Intentional

- Side stripe: a 3px left border is the state channel and appears only where it carries a state or a quotation. Banners stripe in their status colour (danger, success), a field error and a destructive warning stripe in danger, a review step with an error stripes in danger, change cards stripe by severity, and citations take the neutral quotation rule. A stripe that carries no state is removed, not kept.
- Em dash: the interface copy follows this repository's documentation voice, which sets clauses apart with em dashes on purpose.
