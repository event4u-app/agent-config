# Design

## Component taxonomy

Names in this list are bolded, which is an ordinary way to write a list and
must not change whether the declaration is read. None of these names is a
granularity word, so inference cannot reach this answer — only the
declaration can.

- **`shells`** — screen shells
- **`slices`** — feature slices
- **`bits`** — single elements

`vendor` is not a tier; it holds third-party wrappers.
