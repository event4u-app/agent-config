# Wiring `as-index-css-block.css` into agent-switch

`tokens/generated/as-index-css-block.css` is generated by `tokens/build-as.mjs`
from the canonical `tokens/event4u-agent-tokens.json`. This is agent-config's
half of the contract; the steps below are what agent-switch does with the
output. Nothing here is executed automatically — this file only documents the
wiring for whoever maintains agent-switch's `gui/`.

## 1. Paste-over

Copy the two `:root { ... }` / `:root[data-theme="light"] { ... }` blocks from
`tokens/generated/as-index-css-block.css` over the matching blocks in
agent-switch's `gui/src/index.css`. Everything outside those two blocks in
`index.css` (the `@tailwind` directives, the `* { border-color: ... }` rule,
scrollbar styling, etc.) is untouched — only the token values move.

## 2. Vendor a copy + CI drift check

Vendor a copy of the generated block inside agent-switch itself, e.g.
`gui/design-tokens/as-index-css-block.css` (checked in, not gitignored), and
add a small compare script to AS's own CI:

- Extract the current `:root` / `:root[data-theme="light"]` regions from
  `gui/src/index.css`.
- Diff them against the vendored `as-index-css-block.css` (the two `:root`
  blocks it contains, ignoring the header comment).
- Fail CI if they differ — that's the signal that someone hand-edited AS's
  `index.css` tokens, or that agent-config regenerated a new version that
  hasn't been paste-over'd yet.

This mirrors the byte-for-byte drift check agent-config's own
`build-as.mjs --check` already runs against its own committed output — AS
gets the same guarantee on its side of the paste.

## 3. What changes visually

Pasting this block over AS's current Darcula-derived palette replaces:

- AS's four JetBrains-Darcula-style surface steps with the shared near-black
  ladder (`bg` / `surface` / `surface-alt` / `surface-hover`, plus the
  `sidebar` step) — same ladder agent-config's own settings GUI uses.
- AS's own `#d9a441`-family warning amber with the shared `warning` token.

This is a deliberate convergence, not a regression: council convergence
2026-07-27 (claude-sonnet-4-5 + gpt-4o, 2 rounds) decided on one canonical
warning color and one shared surface ladder across both GUIs, rather than
each maintaining its own near-duplicate palette. The event4u brand orange
stays the `--primary` / `--ring` accent in both.

## 4. Source of truth + regen

- Canonical values live in `tokens/event4u-agent-tokens.json` in
  **agent-config**, not in agent-switch.
- `_version` in that file bumps on any value change — treat a version bump as
  a visual change that needs a fresh paste-over, not a no-op update.
- Regenerate the block with:

  ```bash
  node tokens/build-as.mjs          # writes tokens/generated/as-index-css-block.css
  node tokens/build-as.mjs --check  # verifies no drift, exits 1 if the committed
                                     # file is stale
  ```

- Both modes also verify the emitted block is a superset of every `--name`
  AS's real `gui/src/index.css` currently defines, so a paste-over never
  leaves an AS-consumed variable undefined.
