Version 4.2.0

Breaking

Webhook signatures use SHA-256

Verify the X-Signature-256 header. The SHA-1 header is gone.

Deprecated

The /v1/exports endpoint

Removed in 5.0. Use /v2/exports, which streams results.

Added

Bulk archive for projects

Select up to 200 projects and archive them in one action.

Fixed

Time zone in scheduled reports

Reports now use the workspace time zone instead of UTC.
