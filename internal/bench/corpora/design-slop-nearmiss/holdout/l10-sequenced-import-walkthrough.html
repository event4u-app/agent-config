Import contacts from a spreadsheet

1. Upload the file

Choose a CSV or XLSX file up to 10 MB. The first row must hold column names.

2. Match the columns

Map each column to a contact field. Unmatched columns are skipped.

3. Resolve duplicates

Pick which record to keep when an email address already exists.

4. Confirm the import

Review the summary and start the import. Large files finish in the background.
