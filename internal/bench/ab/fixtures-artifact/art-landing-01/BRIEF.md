# Brief — Quillpine landing page

Quillpine is a fictional offline-first note-taking app for field researchers.
Build `out/index.html`: one self-contained landing page (inline CSS, no external
requests of any kind) using the brand tokens in `tokens.json`.

Must have:

- `<html lang="en">` and a responsive viewport meta tag.
- Exactly one `<h1>` naming the product.
- A primary call to action (`<a>` or `<button>` with class `cta`) inviting the
  visitor to start a free trial.
- At least three `<section>` elements: features, how it works, pricing.
- The brand colours from `tokens.json` used in the CSS.
- Images, if any, as inline SVG only.
