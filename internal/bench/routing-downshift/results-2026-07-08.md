# Routing-Downshift Bench — Results 2026-07-08

Claim under test: `downshift-cost-reduction` (`docs/CLAIMS.md`, pre-registered
before data collection). Family: **read-only fan-out** (`task_class:
read-only-fanout`). Corpus: [`corpus.json`](corpus.json) — 10 paired slices,
deterministic ground truth computed from the repo before dispatch.

## Setup

- **Arms:** `downshift` = `lite` tier (claude-haiku via the host Agent-tool
  `model` override) vs `baseline` = `medium` tier (claude-sonnet, session-tier
  proxy — the orchestrator's typical session tier; NOT opus, so the savings
  number is the conservative end).
- **Dispatch:** 20 live subagent dispatches (10 slices × 2 arms) through the
  Claude Code Agent tool, read-only Explore agents, identical prompts per pair.
- **Verification:** deterministic exact match against pre-computed ground
  truth (non-inferiority analog of the `check_quality_regression.ts`
  held-quality threshold; no LLM judge needed for this family).
- **Telemetry:** 20 orchestration audit lines with the Phase-0 routing fields
  written to `agents/runtime/state/audit/2026-07.jsonl` (meets the ≥20-line
  floor of the orchestration-scope gate).

## Verdict — FAMILY-SCOPED PROVE

The downshift claim is **proven for the read-only fan-out family only**:

- Token usage per identical slice is LOWER on haiku (not merely
  same-tokens-cheaper-price) — the 3× price ratio then compounds it.
- The **mechanical-edit family is unmeasured** — its downshift (and the
  deferred Phase-1 tier downgrades: `production-validator` `inherit`→`medium`,
  the bulk re-tier of `model_tier: inherit` skills) stays gated on its own run.
- Single run, n=10 pairs, one host (Claude Code), baseline = sonnet proxy.
  A stronger session tier (opus) would only widen the savings; a weaker one
  (haiku session) makes downshift a no-op by construction.
