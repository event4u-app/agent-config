## Deviations, stated

- **Temperature.** The first request was refused for `temperature`, before any
  successful generation, so the field was removed from all six requests as
  Section 3 prescribes (`run.json`: `temperature_sent: false`).
- **Scoring instructions.** Section 7 asks for the scorers' instructions to be
  frozen before outputs exist. The scorer seats were fixed then
  (`FREEZE-RECORD`), but the instruction text (`score_packages.mjs`, the JSON
  ledger shape and a restatement of Sections 5–6) was written after the six
  outputs were sealed. The orchestrator had not read any output when writing it,
  and it adds no rule beyond Sections 5–6.
- **Reviewer A launched twice.** The first launch wrote its output to a
  relative path inside an empty working directory and produced no file; no
  reviewer-A response existed until the second launch, so no answer was
  selected among alternatives.
- **The orchestrator knew the decoy** from `docs/CLAIMS.md`, which names it. It
  chose nothing the protocol had not fixed and did not score.
