```bash
npx -y @event4u/agent-config init
```

On a desktop this opens a setup wizard in your browser; in CI or with `--yes` it installs from the terminal. [Install options →](/agent-config/getting-started/installation/)

## What your agent does with it

Skills, rules and slash-command workflows installed into the AI coding tools you already use. Your tool still runs the agent; Agent Config changes what the agent is told to do.

## Before and after

**Before.** You ask your agent to add a CSV export. It writes a handler that returns a hard-coded placeholder, the existing tests stay green and it replies "Done — export implemented." Nothing ever ran the new code.

**After.** In Claude Code you ask `@production-validator` whether the branch is really done. It reads the code that would ship, finds the placeholder and answers **NOT READY** with the exact file and line. On a branch that is really finished it answers **READY** and reports nothing. We measured this on two planted cases: one hollow, one clean. {/* claim:wedge-hollow-detection */}

On Claude Code the package can also refuse to let a turn end on "done" when the agent changed files and ran nothing to check them. On every other tool that is an instruction the agent is asked to follow, not a block. {/* claim:conformance-advisory-vs-blocking */}

## Why Agent Config

- **It checks its work.** The agent is taught to analyse before editing, to test and to run something before it claims done. On a weaker model this measurably improved discipline; on a strong model the same test was a published null. {/* claim:discipline-lift-weak-host */}
- **Every tool you use.** One install, in each tool's own format: 23 tools are detected and 20 are supported — 18 get their configuration written directly, Copilot gets a plugin and Claude Desktop a bundle. {/* claim:host-agent-count */} [Which install do I get?](/agent-config/tools/overview/)
- **Blocks where it can, asks where it cannot.** On Claude Code a few checks can refuse an action; on every other tool the rules are instructions. We say which is which. {/* claim:conformance-advisory-vs-blocking */}
- **Leaves cleanly.** Uninstall removes only its own entries and leaves other tools' config byte-identical. {/* claim:surgical-uninstall */} [Uninstall →](/agent-config/getting-started/uninstall/)
- **It costs more tokens, and we say how many.** On Claude Haiku the default costs 3.3× a run with no rules on the task family where it helps and about 1.7× over the full corpus; loading everything costs 11.7×. {/* claim:essential-tier-cost-factor */} [Benchmark & cost, explained →](/agent-config/trust/benchmark-and-cost/)

## How it fits together

<HowItFits>
Slash commands drive the workflows; rules, skills and memory shape how the agent works inside them.
</HowItFits>

You type a slash command in your AI tool. The command loads the skills it needs, the always-on rules keep the agent honest about what it checked, and the result is evidence you can read: a review with file and line, a map, a cost report, a roadmap with ticked steps.
