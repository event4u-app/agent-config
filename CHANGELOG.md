# Changelog

All notable changes to `event4u/agent-config` are documented here.
Format loosely follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/);
versioning policy is documented in [CONTRIBUTING.md](CONTRIBUTING.md#versioning-policy).
Entry-shape contract: [`docs/contracts/CHANGELOG-conventions.md`](docs/contracts/CHANGELOG-conventions.md).

> Entries before 1.3.3 were reconstructed from git history after the fact.
> Early releases did not maintain release notes.
>
> History is split into **eras**. The current era keeps full entries
> inline; prior eras collapse into a single pointer to an archive file
> under [`docs/archive/`](docs/archive/). A drift test
> (`tests/lib/changelog_eras.test.ts`) forces an era split before the
> current era grows past 250 lines.

> **Retro-curation disposition, 2026-09-01** — roadmap
> `road-to-publication-integrity-hard-fail`, blocker `b-retro-curation-scope`,
> option (c). The `### Release highlights` heads of 14.9.0 through 14.13.0 were
> written by the release generator and published without the editorial pass they
> ask for. Two things were repaired: the generator's own authoring instruction,
> which was never release content, is deleted from this file, and the writer no
> longer emits it. The generator-derived head lines below are **preserved as
> published** and deliberately not paraphrased — rewriting a derived claim is
> editorial judgement two prior councils reserved, and a paraphrase of the
> generator's own reason would be truthfully documented uselessness.
> [`docs/archive/`](docs/archive/) is left untouched as historical record. The
> annotated tag messages and the published GitHub Release bodies for 14.9.0
> through 14.13.0 are **immutable** and cannot be repaired at all.

### Release highlights

- **Behaviour changes:** raise the Node floor to 22 (ADR-290) — unblocks the 17.0.0 cut (#2565) (76f4136); A setup that decides itself: Phase 4 removes the keys, and nothing reads them (#2532) (d8f5590); The source door takes its decided name, the observation slots stay unspent, and the calibration reads zero (#2544) (32a66d7); Brand drain: lexicon and claim check on every finished draft, scenario fixtures, claims (5.3, 5.4, 7.2, 7.3) (#2486) (6c312e1); A canvas the code owns: claude-design lane, /design-system:sync, Lock carrier (#2470) (72f7580); Type design: an original font as a measured system, gated and witnessed (#2462) (1876e18); +13 more.
- **Default changes + migration:** Steps the skill cannot skip: two pilots split, and a default-off procedure cursor (Phases 4-5) (#2466) (e3cf6dc); read member CLI output beyond the default spawn buffer (#2348) (2fa431c). Breaking, pending in `BREAKING_CHANGES.md` and shipped by this release: **Three `fail_closed` hook guards run where they were silent.** The installed claude hook command now reaches a dispatcher staged under `~/.event4u/agent-config/runtime/` after a project-local install and before `PATH` ([`3f8c98e`](https://github.com/event4u-app/agent-config/commit/3f8c98e74), #2455). On machines installed through `npx`, or hosts launched with a bare `PATH`, every hook command used to end in a silent `exit 0`; there `block-no-verify` (refuses `git … --no-verify` and `core.hooksPath` overrides), `block-kernel-rule-writes` and `block-plumbing-writes` (refuse agent writes to this package's kernel rules and hook plumbing) now run and may refuse a tool call for the first time. Classed breaking by the AI council, 2026-10-19 (`agents/evidence/council/hook-carrier-release-note-class-20261019.md`). **`uninstall --global --purge` stops being a recursive delete of the host anchor.** Old scope: `fs.rmSync(anchor, { recursive: true })` on whole host configuration roots — `~/.claude/`, `~/.codex/`, `~/.config/zed/` — so everything under them went, whoever wrote it. New scope: only the anchor-relative paths this package's own deploy inventory recorded writing; the anchor itself is never removed, directories are pruned only when left empty, a recorded symlink is unlinked rather than followed, and a purge with no readable inventory for that anchor exits 1 having deleted nothing. A second change in the same area: a plain `uninstall --global` now keeps the lockfile while recorded content is still on disk, where it used to delete it.
- **Security and correctness:** let the release-shape gate accept the impact-map entry the release writes (#2569) (4123ea8); stop refusing a breaking commit that lost its Consumer-Impact trailer (#2567) (95dbe28); let sync-visibility write metadata with RELEASE_PR_TOKEN (#2566) (88df4bc); Revert "Revert "fix(review): R2 findings on the routing ratchet and the settled closures"" (1e79ede); Revert "fix(review): R2 findings on the routing ratchet and the settled closures" (d536771); R2 findings on the routing ratchet and the settled closures (cc83373); +25 more.
- **Honest nulls:** Blocker sweep follow-up: the three owner answers recorded (#2521) (221cd5d); Canvas 7.3: the taught baseline line, its corpus and the re-pinned routing measurements (#2502) (6c84bdf); A brand the tree can check: palette tags, voice slot, lexicon checker, zero brand bytes (#2433) (debb26d); A search answer a model can choose from (#2331) (b8f248b).
- **Known limitations:** The update concerns' code, hardened and unregistered: eleven council rounds, two delivery gaps named (#2545) (src/scripts/_lib/update_notice.ts declares a residual) (7aa764a); A setup that decides itself: Phase 4 removes the keys, and nothing reads them (#2532) (src/scripts/install.ts declares a residual) (d8f5590); Install and hook runtime: foreign skills are not ours, a global dry run shows the global plan, and a fresh worktree's hooks run (#2553) (src/scripts/_cli/doctor_ownership_ledger.ts declares a residual) (4338b2e); Update that installs itself: a machine-wide session register, a consent key and the ring-0 record land; the session concerns wait on the council (#2533) (src/scripts/_lib/update_notice.ts declares a residual) (ea1e201); Skills that arrive when called: Phase 3 closes HARM, Phase 4 ships, and the effect read changed 4.1 twice (#2529) (src/scripts/install.ts declares a residual) (c43740e); Hook carrier roadmap closed: Pending breaking rows reach the release head (4.1) (#2524) (src/scripts/_lib/release_highlights.ts declares a residual) (5c4d546); +10 more.
