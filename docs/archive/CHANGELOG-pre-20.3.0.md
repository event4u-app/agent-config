> **Read-only.** New entries land in `CHANGELOG.md`. Entries
> here are not rewritten — git tags remain the canonical source
> for what shipped. The one amendment an archive permits is a
> **correction that adds**: where a published entry says something

> deleted, so both the original claim and its correction stay

### Release highlights

- **Behaviour changes:** three round-29 body/contract mismatches (eaeb9f7); startup contracts live in their own files, not inside the rule (13fc2d7); pii contract activates on every draft, log code and export, as its law does (5be9170); pii contract activates on any log code and on a secret alone (e4c4ad4); pii contract activates on the non-personal values it masks (4d74fa7); pii contract replaces the sector fields the body names, personal or not (c5f0f3c); +25 more.
- **Default changes + migration:** pass the default open flag through the openSync spies (5754c5a); remove a default asset only through a removal record (0c2120c); close a roadmap that changed a default asset only with a measurement line (1cae677); a new default knob without a policy row fails check_claims (proof-where 7.1) (50209ce); where the main session's default context goes (6e52999); measure the main-session default context per asset (proof-where 3.1) (b70ddcf); +2 more.
- **Security and correctness:** type timeout_result as RunResult (ace3001); a stream-mode timeout keeps its stream, so a pre-model timeout is rerun (2015168); gate contracts read a full base, not a depth-1 refetch (5721e61); resolve a profile from the published package's dist tree (e483d3f); replay CI before the push and stamp it; pre-push only checks the stamp (3fa9288); collect every failure locally; leave the ratification-gated workflow alone (1225890); +143 more.
- **Honest nulls:** act on the honesty run — guardrail review, matrix row, amendment; carry the detector and archive the roadmap (7836566).
- **Known limitations:** keep installed_source_value inside install.ts's size ratchet (src/scripts/install.ts declares a residual) (2427207); drop the dist/agent-src/rules/ prefix from an installed rule's source_path (src/scripts/install.ts declares a residual) (fd3ca92); full-vs-reduced rule layer comparison — reads inferior (#2938) (internal/bench/core/bench_ab_v2_stats.ts declares a residual) (3fe316d); keep detector G as a bench instrument, not a live count (internal/bench/core/_lib/capitulation_predicate.ts declares a residual) (3967ee3); write the reduced rule layer on install and upgrade (src/scripts/install.ts declares a residual) (6322154); run one paired sweep with and without the fixture's memory (internal/bench/core/bench_ab_v2_stats.ts declares a residual) (b1057a5); +5 more.
